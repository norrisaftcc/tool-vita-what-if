# The Algorithm™ Methodology
## "Iterations are features. Comfort is a bug."

### Origin Story
Born from 47 iterations in 14 days during the VITA presentation sprint, The Algorithm proved that process IS product when your process delivers continuous customer value at uncomfortable velocity.

## Core Principles

### The Sacred Numbers
- **47/14**: Our proven baseline (47 iterations in 14 days)
- **3.36**: Minimum daily iteration velocity
- **5**: Maximum standup duration in minutes
- **7-8**: Optimal Product Owner stress level (out of 10)
- **30**: Target iteration cycle in minutes

### The Four Pillars

#### 1. Velocity Over Comfort
Comfort is actively managed as a bug. When everyone feels comfortable, velocity has died.

#### 2. Ship Over Meet
Every meeting that could be a deployment should be a deployment. Meetings are extinct.

#### 3. Show Over Tell
Documentation through demonstration. Your running code is your documentation.

#### 4. Iteration Over Perfection
Perfect is the enemy of shipped. Ship at 70%, iterate to 100%.

## Implementation Framework

### Day 0: Initialization
```
1. Install deployment pipeline (30 min)
2. Set up iteration counter (15 min)
3. Configure PO stress monitor (15 min)
4. Delete all meeting invites (5 min)
5. Ship first iteration (25 min)
```

### Daily Rhythm
```
09:00 - 5-minute standup (standing required)
09:05 - Ship iteration 1
10:00 - Ship iteration 2
11:00 - Ship iteration 3
12:00 - Lunch (optional if velocity drops)
13:00 - Ship iteration 4
14:00 - Ship iteration 5
15:00 - Ship iteration 6
16:00 - Ship iteration 7
17:00 - Velocity review & shame/fame
```

### The Product Owner Management Protocol

#### Optimal Discomfort Zone (7-8/10)
- **Too Comfortable (< 6)**: Velocity intervention required
- **Optimal (7-8)**: Maintain current iteration rate
- **Dangerous (> 9)**: Provide coffee, continue shipping

#### Stress Induction Techniques
1. **Level 1**: "We're pivoting slightly"
2. **Level 2**: "The client has feedback"
3. **Level 3**: "Demo is in 2 hours"
4. **Level 4**: "The client is watching our commits"
5. **Level 5**: "Every iteration is being live-streamed"

## Metrics That Matter

### Customer Joy Index (CJI)
```
CJI = (Features Shipped × User Feedback Score) / Days Elapsed
```

### Product Owner Sweat Index (POSI)
```
POSI = (Iterations/Day × Pivot Count) / Coffee Consumed
```

### Team Velocity Score (TVS)
```
TVS = (Actual Iterations / 3.36) × 100%
```

## Success Indicators

You're doing The Algorithm correctly when:
- PRs are merged before coffee cools
- Your git log looks like abstract art
- The PO's fitbit thinks they're exercising
- Customers send thank you notes
- Other teams ask "How do you ship so fast?"
- You've forgotten what a meeting feels like

## Failure Modes

You've abandoned The Algorithm if:
- A day passes with < 3 iterations
- Meetings appear on calendars
- The PO is relaxed
- You're writing documentation before code
- "Perfect" enters your vocabulary
